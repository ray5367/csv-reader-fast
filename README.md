A fast drop-in for csv-reader 1.0.0 that reads broken CSV files exactly as the reference does, using index scans and slices instead of character-at-a-time parsing.

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
